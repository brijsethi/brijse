# my-2nd-brain — Getting Started

The getting-started guide for `my-2nd-brain`, the tool behind this very vault. Explains
the core loop (inbox → FETCH → raw/ → INGEST → wiki/{pages,sources,views} →
QUERY/VIEW), the three file types (source, page, view), the seven operations (FETCH,
INGEST, FORGET, QUERY, VIEW, REFLECT, LINT) and their triggers, four slash commands
(/save, /view, /reflect, /forget), and five governing invariants (raw/ immutable, every
claim cited, paraphrase not copy, user curates, shareable:true views frozen).
