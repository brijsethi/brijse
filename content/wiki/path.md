# Learning Path

The curator's queue: what to consume next, why now, and what you'd make from it.
Sits one layer **above** `inbox.md` — items here are *candidates*. When you commit
one, it flows:

> **path → inbox.md → FETCH → raw/ → INGEST → wiki/**

Notes made during INGEST can spawn new candidates back here. That loop is the point.

**Every item carries a `make:` hook** — the artifact it feeds (post / slides /
workshop / visual), or an honest `foundation` when it has no direct output yet.
An item with no plausible `make:` is a side-trail — flag it, don't queue it.

**Aim:** build Brij's own AI fluency first, then teach it. Target audience still
emerging. The tracks are *instruments* — whichever one keeps filling up tells us
where his attention actually goes, and (for Prerequisites) which audience he's
drawn to serve.

**Tiers per track:** `Now` (1 active) · `Next` (curator-ranked, ~3) · `Someday` (backlog / tempt-me pile).

## Weekly review
**Last reviewed:** never — first review due.

Each week the curator will:
1. Note what you consumed (new `wiki/sources/`) and what your notes spawned.
2. Re-rank each track's `Next`.
3. **Name any side-trail** — an item with a weak or absent `make:` hook — so you can cut it consciously.
4. Flag which Prerequisites sub-thread is filling up (your niche, emerging).
5. Update **Last reviewed** above.
